
# CODSOFT Data Science Internship

## Task 3: Iris Flower Classification

### Objective
To classify iris flowers into Setosa, Versicolor, and Virginica using machine learning.

### Technologies Used
- Python
- Google Colab
- Scikit-learn
- Matplotlib

### Model
Support Vector Machine (SVM)

### Dataset
The Iris dataset contains 150 flower samples and four measurement features.

### Result
The model achieved 96.67% accuracy on the test set (29 correct predictions out of 30).

### How to Run
Open the notebook in Google Colab and run the cells from top to bottom.
